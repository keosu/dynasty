共13组轮廓，西夏有两个不同年份的版本。四场景的所有参与政权都能从朝代选择器进入；在筛选范围内，教材场景优先于未校订旧快照。范围外仅允许手动参考。辽与金不跨年拼在同一图；1142年的金都城是上京会宁府，并非后来迁都的燕京。572年的后梁是西梁，不是五代后梁；名录关联到包含西梁君主的梁朝专题，按572年筛选出萧岿。

政权名、都城、颜色、说明、PDF路径索引及配准控制点保存在 `scripts/conflict-maps.json`；输出为 `public/data/conflict-boundaries.json`。`src/data/generated/conflict-periods.json` 为同一脚本生成的轻量入口索引。前端以一个场景统一选择、统一适配地图，逐政权渲染与开关，未把不同年份的多边形混合成“同时并立”。

配准均方根残差（2倍渲染像素）分别为4.48、10.99、4.51、3.18。572年原图高度概化，最大控制点残差18.88像素、留出最大28.54像素，因此使用单独记录的20／32像素验收上限，并在界面提示其低精度；其余三图仍采用10／18像素上限。这些指标只评价配准，不保证历史地理边界精度。572年海南只有图框内的北部轮廓，未补画截断部分。所有场景均未配准南海附图；1111、1142图的大理及若干周边政权未着色，不应理解为这些政权不存在。

PDF色块在岸线自接处可能生成含退化线段的GeometryCollection，生成器保留全部面分量、去掉退化线段，避免漏掉大块陆地。同图边缘少量色块交叠按配置的叠放次序裁开，后梁等小区域优先保留，避免双重着色。最终校验都城与名称位置位于相应疆域内，且一个都城不会落入两个政权色块。

## 数字化方法与误差

1. 核验PDF散列，按固定页码和路径索引读取地图色块轮廓；不以现代边界补齐疆域。
2. 每张图选取10—13个驻所及自然地理控制点，记录2倍渲染图像中的像素坐标。
3. 原图缺少投影元数据，使用拟合的Lambert正形圆锥投影和仿射转换配准；采样Bezier曲线，按0.015度容差简化，保留多边形拓扑。
4. 保存残差与逐点留出校验。2倍渲染下均方根残差约3.35、3.01、4.55像素，最大逐点留出误差约10.96、7.17、10.68像素。**这只是配准误差，不能解释为真实历史边界的位置精度**。本数据不适用于测距、面积统计或精细考证。
5. 前端统一球面环方向，完整适配疆域范围，避免西域在初始画布外。测试校验龟兹、轮台、于阗、北庭、伊犁等点，及唐图没有错误包含拉萨。

## 维护与复现

```powershell
.venv/Scripts/python -m pip install -r scripts/requirements-map.txt
.venv/Scripts/python -X utf8 scripts/georeference_textbook.py
npm run test
npm run test:e2e -- tests/boundaries.spec.ts
```

- `scripts/textbook-maps.json`：底本、散列、页码、图形路径、控制点、时间口径与覆盖说明。
- `scripts/georeference_textbook.py`：可复现的图形读取、配准及GeoJSON生成。
- `public/data/textbook-boundaries.json`：三个新参考图层及来源、配准报告。
- `public/data/historical-boundaries.json`：旧版18快照存档，合并时无条件排除汉唐清的5个旧快照；教材文件加载失败也不恢复旧图。
- `src/domain/boundaries.ts`：只自动选取与范围相交的参考图，不外推或插值。手动指定其他年代不会改变事件筛选；再次修改时间范围即取消指定。
- `src/data/westernRegions.ts`：五条西域治理事件，官方文字证据与概略点位分开陈述。

更换教材版本时须重新核验图形索引和控制点，不可只换URL。接入正式授权的历史GIS后，应记录出版者、版本、许可、有效年份、控制／行政关系语义及精度，再替换相应专题。
