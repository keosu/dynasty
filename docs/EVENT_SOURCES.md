## 维护入口

- `src/data/events.ts`：保留原有行式数据并合并三个来源。
- `src/data/events-expanded.ts`：本次补充的完整 `HistoricalEvent` 对象，人工维护，不是抓取输出。人物使用最终名录中的稳定 ID，不在运行时猜测姓名。

页面、地图热点、人物关联及语音共用合并后的 `events`。新增事件无需改页面，来源名称和 URL 会在详情中展示。坐标是概略定位，不是教材或维基百科提供的精确 GIS 坐标。

## 本次来源核对的实际范围

70 件补充事件中，56 件附教材背景页，12 件附本地已保存的相关人物条目；诸葛亮北伐、六镇起义目前仅有维基百科事件条目作为延伸阅读入口，仍待补充史料卷次或可核验教材专页。

教材取自本项目已保留的三个 PDF：人教社《中外历史纲要（上）》《中国历史·七年级上册》《中国历史·七年级下册》。链接指向 TapXWorld/ChinaTextbook 的固定版本 `5a80345f2043ba6f8db8d7be9cf3db82725ff1f7`，不是出版社直接下载服务。引用页码为 PDF 页码，含封面与前言，不等于印刷页码。高中及七年级下册的缓存散列见 `scripts/textbook-maps.json`。不在仓库重新分发完整教材。

本次阅读了相关教材文字及部分人物缓存，编写概括性正文；教材引用标为“教材背景”，仅支持相应背景与主要事实，不能视为逐句、逐坐标或全部起止年份都已通过教材核验。人物缓存为先前采集的维基百科页面，未重新全量抓取。事件专页在线访问返回 HTTP 403，因此其链接明确标作“延伸阅读”，不宣称本次已成功访问或完成学术审订。

本地研究中间材料在 `.cache/event-*.json` 和 `.cache/textbook-event-pages.json`，均不进入运行时、不提交。后续通常只需读取本文件和对应事件对象；无需重跑 PDF 提取或全量人物抓取。

## 纪年和定位约定

- 西晋建立按教材公元 266 年；正文说明传统年表常列 265 年。未借此更改原有朝代元数据和全部人物年表。
- 东晋建立用通常的 317 年，并说明当年称晋王、318 年称帝。
- 安西都护府于 640 年设立，初治交河；迁治龟兹、四镇形成另有时间节点。点位在交河故城附近。
- 六镇动乱区间含 523 年怀荒起事、524 年扩大和 525 年镇压；并不表示此后北方动乱结束。此条仍需补充专门史料。
- 元和中兴采用元和年号的 806—820 年；襄樊围攻采用 1268—1273 年，正文区分蒙古时期与元朝定国号之后。
- 毕昇活字印刷使用庆历年间 1041—1048 年，不能造出精确发明年和发明遗址。开封仅为时代参照。
- 澶渊之盟的谈判跨公历年，用 1004—1005 年；鉴真抵日采用教材常见的 754 年。
- 建国、改革、历法多取政治中心；战争、旅行及工程只选一个代表点。古战场、古海岸线与地点异说在正文说明，不把一个点当成完整行军路线或范围。
- 事件归属一个主要朝代专题，交战另一方可通过人物关联进入；人物关系不是“全都在位”或“全部亲自参与”的断言。如赤壁之战归东汉，不提前改归尚未建立的三国。
