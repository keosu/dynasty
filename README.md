# 山河纪 · 历代王朝百科

以地图为主工作区的历史探索应用。青瓷亮色、静夜暗色和琉璃夜色三种主题，固定底部双端时间轴、可折叠可调宽侧栏，支持手机与桌面浏览。

继续开发先读 [AI 接续入口](AGENTS.md) 和 [当前状态与交接](docs/HANDOFF.md)，其中记录了疆域覆盖、已知缺口、任务文件索引及验证状态。

## 启动

需要 Node.js 20.19+ 或 22.12+（本次使用 Node.js 24）。

```sh
npm install
npm run dev
```

打开终端显示的本地地址，默认为 `http://localhost:5173`。

```sh
npm run build       # 类型检查与生产构建，输出 dist/
npm run preview     # 本地预览生产构建
npm test            # 数据引用、纪年、复位与疆域投影验证
npx playwright install chromium  # 首次浏览器验证需要
npm run test:e2e    # 浏览器交互与移动端布局验证
npm run test:pwa    # 生产构建的 Pages 子路径、离线、安装入口与更新验证
```

可把 `dist/` 部署到任意静态托管。页面使用 Hash 路由，详情页直接打开或刷新不需要服务器重写规则。如果部署到子目录，请使用 `npx vite build --base=/子目录/`。

## PWA 与 GitHub Pages

站点地址：[山河纪](https://keosu.github.io/dynasty/)。推送到 `main` 后，GitHub Actions 自动执行测试、构建并部署到 Pages；PR 只运行验证。配置与排查方法见 [部署说明](docs/DEPLOYMENT.md)。

支持安装的浏览器会显示顶部安装按钮，也可使用浏览器菜单安装。iPhone / iPad 使用 Safari 的分享菜单 → 添加到主屏幕。首次联网打开并提示“已可离线使用”后，应用、地图、目录和世系可离线重开；人物长篇正文阅读后缓存，最多 400 份、30 天，未读正文和外部来源仍需联网。新版本准备好后提示“立即更新”，由用户选择刷新时机。

```sh
npm run build:pages # 构建 /dynasty/ 子路径版本
npm run preview -- --base=/dynasty/
npm run icons       # 修改 favicon.svg 后重新生成安装图标
```

PWA 需要 HTTPS 或 localhost；开发服务器不注册 Service Worker。生产预览请打开终端地址下的 `/dynasty/`。浏览器清理网站存储后需要重新联网加载，系统语音的离线可用性取决于设备。

## 当前功能

- 固定视口工作区：顶部导航与工具栏、中间交互地图、底部朝代时间轴。地图页和世系页不需要整页滚动；长内容在面板内阅读。
- 顶部调色盘切换青瓷亮色／静夜暗色／琉璃夜色。琉璃以中性色背景承载信息，用栏目识别色和事件类别色建立层次；事件带类别文字与图标，选中状态统一突出。主题支持键盘选择，自动保存并用于所有页面。
- 双端时间轴：直接拖动左右手柄、键盘微调、精确输入年份、放大本朝。筛选跨政权的在位君主和事件。
- 地图：滚轮缩放、双击放大、拖动、键盘移动、事件聚合与选择、河流湖泊／历史疆域／热点／经纬网图层。
- 事件与人物在可关闭的侧栏中打开；桌面侧栏支持拖动右下角改变宽度，小屏默认收起探索栏。
- 392 位君主、65 个政权专题、101 件精选事件；完整导入来源主表的人物名录、在位数据与人物正文。
- 事件目录采用自适应多列卡片，支持朝代、类别、关键词筛选与年代排序，可直接定位地图。新增事件与来源独立维护，核对范围和待校订项见 [事件资料记录](docs/EVENT_SOURCES.md)。
- 在位顺序图逐段显示复位；血缘图只连接有明确来源的父子关系。支持查找、平移、缩放和人物档案。
- 列表与人物卡片使用更清楚的阅读字号；世系默认保持可读大小，支持“查看全图”和重置。手机不会为了塞进全部节点而自动缩小文字。
- 长篇人物摘录按人物单独加载，避免把全部正文塞入首次加载。
- 语音讲解支持播放、暂停、继续与停止。

## 架构与目录

完整规划见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

```text
src/
  data/          朝代、人物、事件与更替关系，纯结构化数据
  domain/        类型、区间查询、搜索与投影规则，附单元测试
  components/    地图、时间轴、语音与公共组件
  pages/         地图首页和各百科页面
  App.tsx        路由、全局搜索与共享筛选状态
  app.css        紧凑布局、工作区与响应式样式
  themes.css     三种主题的语义配色、材质及选择器样式
  theme.ts       主题目录、偏好读取与启动应用
  styles.css     百科阅读组件基础样式
public/data/     自然地理底图、历史边界快照、分人物正文与数据许可证
scripts/        可复用的君主／边界采集器
tests/          Playwright 端到端交互检查
docs/           架构、扩展计划与数据维护说明
```

技术栈：React 19、TypeScript、Vite、D3 Geo、TopoJSON、Lucide。无后端、无 API 密钥、无数据库依赖。界面使用系统字体，没有外部字体请求。地图底图本地分发，浏览核心功能无需第三方地图网络请求。

## 数据覆盖与参考

已采集《中国君主列表》秦至清主表中的 **392 条君主记录、65 个政权专题**，对应人物正文全部获取成功。包含源表所列的并立、前身、延续、自立或摄政等记录，不将这一次来源采集宣称为全历史所有称帝者的最终定论。来源条目、提取范围和原始在位文字保留在数据中，原有校订资料优先合并。

完整采集流程、范围、异常处理、数据结构与许可证见 [docs/DATA_IMPORT.md](docs/DATA_IMPORT.md)。维护方式见 [docs/DATA_GUIDE.md](docs/DATA_GUIDE.md)。

地图使用本地 Natural Earth 1:50m 自然地理底图。西汉、唐、清改用教育部组织编写、人教社出版的教材地图进行数字化配准，包含西域，分别为西汉后期、669年、1820年参考。**这是教材底本的配准衍生数据，并非官方GIS。** 其他朝代的13个旧快照仍标为“未校订”，不冒充中国官方来源；没有参考图时不再回退到手绘多边形。时间范围以外的图层只允许显式手动参考。来源、精度及尚未解决的覆盖问题见 [疆域校订记录](docs/BOUNDARY_SOURCES.md)。

并立时期新增 **4个同年场景、13组政权轮廓**：三国262年、南北朝后期572年、北宋／辽／西夏1111年、南宋／金／西夏1142年。地图独立着色并标注政权、都城，点击可读简介、当年在位者和语音；时间轴新增相应政权分段。数据在 `public/data/conflict-boundaries.json`，配准底本与路径在 `scripts/conflict-maps.json`，同一离线脚本可重新生成。南北朝572年图比其他三图概化程度高；未处理的周边政权和附图在来源面板说明。

人物摘录遵循 CC BY-SA 4.0；Natural Earth 为公有领域；Historical Basemaps 旧数据遵循 GPL-3.0。教材原图权利归原权利人，不声明开放许可，原教材审图号不适用于本站配准结果。新增西域事件依据国务院新闻办公室公开白皮书，文献日期与概略点位分别说明。

语音依赖 Web Speech API、系统中文语音包及浏览器实现，部分声音可能需要联网。浏览器测试验证控制行为，不代替真实设备上的音质验收。

## 验证

`npm test` 验证纪年、复位、名录数量、别名去重、来源引用与地图方向。`npm run test:e2e` 验证双端手柄、主题持久化、面板、地图交互、世系、正文按需加载及移动工作区。`npm run format:check` 检查格式。
